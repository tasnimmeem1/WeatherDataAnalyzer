**Weather Data Analyzer**
A JavaFX application that reads weather data from a CSV file and displays daily readings, weekly summaries, and monthly temperature averages.

## Features
- Displays seven days of weather from a selected date.
- Calculates weekly and monthly average temperatures.
- Counts days above an entered temperature.
- Counts rainy days in the displayed week.
- Shows daily temperature, humidity, and rainfall.
- Switches between Celsius and Fahrenheit.
- Displays animated weather illustrations.
- Uses sample weather data for all 365 days of 2026.
- Uses CSS for dashboard styling.

## Modern Java Features
- Records to represent weather data.
- Enhanced switch to determine weather categories.
- Text blocks to format reports.
- Lambdas and streams to process data.
- Markdown Javadoc to document the code.
- Records and interfaces without explicit class declarations.
 
## Technologies
- Java 23 or newer
- JavaFX
- Maven
- FXML
- CSS

  
## How to Run
1. Install JDK 23 or newer.
2. Download or clone this repository.
3. Open pom.xml as a project in IntelliJ IDEA.
4. Allow Maven to load the dependencies.
5. Set the Project SDK and Maven runner JDK.
6. Run these commands from the project folder:Dataset
   
The weatherdata.csv file contains synthetic sample data for 2026, including date, temperature, humidity, and precipitation.
